# LAB-001 — Integração SimC CLI

## Objetivo

Executar o SimulationCraft pinado de forma headless, reproduzível e segura, produzindo artefatos estruturados para o
Rotation Lab e diagnósticos acionáveis quando a execução não puder começar ou terminar corretamente.

## Escopo

- validar o pin, a presença do executável e seu SHA-256 antes de cada execução;
- registrar versão do SimC, versão/build do WoW, commit do engine e commit do workflow de publicação;
- oferecer comandos para diagnóstico da instalação, execução de perfil e smoke real;
- aceitar um perfil `.simc` dentro do repositório e opções básicas tipadas de iterações, threads e duração;
- invocar o processo sem interpolação por shell;
- gerar o relatório JSON nativo do SimC e um manifesto de execução do Rotation Lab;
- gravar manifesto também nas falhas do processo, com código, categoria e saída limitada;
- mapear os códigos de saída documentados pelo SimC para mensagens acionáveis;
- cobrir o runner com testes determinísticos usando processo injetado;
- manter uma fixture mínima de smoke, sem tratá-la como baseline de Enhancement.

## Fora do escopo

- baixar, atualizar ou compilar automaticamente uma nova versão do SimC;
- importar APL comunitária ou definir a DSL (`LAB-002` e `LAB-003`);
- definir matriz ST/Cleave/AoE (`LAB-004`);
- criar baseline, catálogo ou regras de Enhancement;
- otimizar prioridades ou comparar performance;
- publicar relatórios ou releases.

## Critérios de aceite

- `npm run simc:doctor` confirma metadados, executável e hash pinados;
- `npm run simc:run -- --profile <arquivo>` executa sem shell e gera os dois relatórios;
- o manifesto registra versão/build, commits, hashes, perfil, opções, duração e status;
- caminhos fora das fronteiras permitidas e opções inválidas são rejeitados antes da execução;
- códigos de saída conhecidos produzem categoria e orientação específicas;
- `npm run simc:smoke` executa uma simulação real e curta com o binário pinado;
- testes cobrem sucesso, binário ausente, hash divergente, perfil inválido e falha do SimC;
- `npm test` permanece verde.
